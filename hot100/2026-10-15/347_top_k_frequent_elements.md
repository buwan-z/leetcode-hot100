# 347. 前 K 个高频元素

来源：[LeetCode 347](https://leetcode.cn/problems/top-k-frequent-elements/)。本题改编为 ACM 标准输入输出格式，每次运行处理一组数据。

## 题意

给定长度为 n 的整数数组 nums 和整数 k，找出出现频率最高的 k 个不同整数。保证这 k 个整数构成的集合唯一。请使选择这些元素的时间复杂度优于 O(n log n)。为便于核对，最终输出时将选中的 k 个整数按数值升序排列。

## 输入格式

第一行输入两个整数 n 和 k。第二行输入 n 个整数，表示 nums。

## 输出格式

输出一行 k 个整数，表示前 k 个高频元素，按数值升序排列，以空格分隔。

## 样例 1

输入：

```text
6 2
1 1 1 2 2 3
```

输出：

```text
1 2
```

## 样例 2

输入：

```text
1 1
1
```

输出：

```text
1
```

## 数据范围

- 1 ≤ n ≤ 10^5。
- -10^4 ≤ nums[i] ≤ 10^4。
- 1 ≤ k ≤ 数组中不同整数的数量。
- 答案集合唯一；当 k 小于不同整数数量时，第 k 高频元素的频率严格高于其余未选元素。
- 上述复杂度要求针对选择过程；本 ACM 版本额外要求对输出的 k 个元素排序。
