# 238. 除了自身以外数组的乘积

来源：[LeetCode 238](https://leetcode.cn/problems/product-of-array-except-self/)。本题改编为 ACM 标准输入输出格式，每次运行处理一组数据。

## 题意

给定长度为 n 的整数数组 nums，构造数组 answer，使 answer[i] 等于 nums 中除 nums[i] 以外所有元素的乘积。要求时间复杂度为 O(n)，且不能使用除法。进阶：除输出数组外，只使用 O(1) 额外空间。

## 输入格式

第一行输入整数 n。第二行输入 n 个整数，表示 nums。

## 输出格式

输出一行 n 个整数，依次表示 answer，以空格分隔。

## 样例 1

输入：

```text
4
1 2 3 4
```

输出：

```text
24 12 8 6
```

## 样例 2

输入：

```text
5
-1 1 0 -3 3
```

输出：

```text
0 0 9 0 0
```

## 数据范围

- 2 ≤ n ≤ 10^5。
- -30 ≤ nums[i] ≤ 30。
- 任意前缀、任意后缀的乘积，以及每个 answer[i]，均在 32 位有符号整数范围内。
