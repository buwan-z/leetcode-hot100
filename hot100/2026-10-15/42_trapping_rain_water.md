# 42. 接雨水

来源：[LeetCode 42](https://leetcode.cn/problems/trapping-rain-water/)。本题改编为 ACM 标准输入输出格式，每次运行处理一组数据。

## 题意

给定 n 个非负整数 height，表示从左到右排列的柱子高度，每根柱子宽度均为 1。计算下雨后这些柱子之间最多能够接住多少单位的雨水。两端以外的水会流走。

## 输入格式

第一行输入整数 n。第二行输入 n 个整数，表示 height。

## 输出格式

输出一个整数，表示能够接住的雨水总量。

## 样例 1

输入：

```text
12
0 1 0 2 1 0 1 3 2 1 2 1
```

输出：

```text
6
```

## 样例 2

输入：

```text
6
4 2 0 3 2 5
```

输出：

```text
9
```

## 数据范围

- 1 ≤ n ≤ 2 × 10^4。
- 0 ≤ height[i] ≤ 10^5。
