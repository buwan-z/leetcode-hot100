# 200. 岛屿数量

来源：[LeetCode 200](https://leetcode.cn/problems/number-of-islands/)。本题改编为 ACM 标准输入输出格式，每次运行处理一组数据。

## 题意

给定 m 行 n 列的网格，字符 1 表示陆地，字符 0 表示水。水平或竖直相邻的陆地属于同一座岛屿，对角相邻不算连通。网格四周均视为水。求岛屿数量。

## 输入格式

第一行输入两个整数 m 和 n。接下来 m 行，每行输入一个长度为 n、仅含字符 0 和 1 的字符串，字符之间没有空格。

## 输出格式

输出一个整数，表示岛屿数量。

## 样例 1

输入：

```text
4 5
11110
11010
11000
00000
```

输出：

```text
1
```

## 样例 2

输入：

```text
4 5
11000
11000
00100
00011
```

输出：

```text
3
```

## 数据范围

- 1 ≤ m, n ≤ 300。
- 每个网格位置只能为字符 0 或 1。
