# 24. 两两交换链表中的节点

来源：[LeetCode 24](https://leetcode.cn/problems/swap-nodes-in-pairs/)。本题改编为 ACM 标准输入输出格式，每次运行处理一组数据。

## 题意

给定一个单链表，将每两个相邻节点交换，并输出交换后的链表。若节点数为奇数，最后一个节点保持原位。练习时请构建单链表并调整节点之间的链接完成交换，不能仅修改节点中存储的值。输入输出使用从头到尾的节点值序列表示链表。

## 输入格式

第一行输入整数 n，表示节点数量。若 n > 0，第二行输入 n 个整数，依次表示从头到尾的节点值；若 n = 0，则没有第二行。

## 输出格式

输出一行，包含交换后从头到尾的节点值，以空格分隔。若链表为空，输出一个空行。

## 样例 1

输入：

```text
4
1 2 3 4
```

输出：

```text
2 1 4 3
```

## 样例 2

输入：

```text
3
1 2 3
```

输出：

```text
2 1 3
```

## 样例 3

输入：

```text
0
```

输出：

```text

```

### 样例说明

样例 3 表示空链表，输出代码块中的空白行即为一个换行符。

## 数据范围

- 0 ≤ n ≤ 100。
- 0 ≤ 节点值 ≤ 100。
