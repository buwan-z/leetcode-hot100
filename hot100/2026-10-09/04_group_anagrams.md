# 49. 字母异位词分组（LeetCode 49）

给定一个字符串数组 `strs`，请把所有由相同字母组成的字符串分到同一组。返回各组的顺序不限，组内字符串的顺序也不限。

## ACM 输入格式

第一行输入整数 `n`，表示字符串数量。
接下来 `n` 行，每行输入一个只包含小写英文字母的非空字符串。

## 输出格式

第一行输出分组数量 `k`。
接下来输出 `k` 行，每行表示一组：先输出组内字符串个数 `m`，再输出该组的 `m` 个字符串，均以空格分隔。各组和组内元素顺序不限。

## 样例

输入：
```text
6
eat
tea
tan
ate
nat
bat
```

输出（任意等价分组均可）：
```text
3
3 eat tea ate
2 tan nat
1 bat
```

## 数据范围

- `1 <= n <= 10^4`
- `0 <= len(strs[i]) <= 100`
- `strs[i]` 只包含小写英文字母。
