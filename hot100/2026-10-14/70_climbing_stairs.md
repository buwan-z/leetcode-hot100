# 70. 爬楼梯（Climbing Stairs）

来源：[LeetCode 70](https://leetcode.cn/problems/climbing-stairs/)，属于 LeetCode Hot 100。本题将原题改编为 ACM 标准输入输出格式；每次运行只处理一组数据。

## 中文题意

楼梯共有 n 阶，每次可以向上爬 1 阶或 2 阶。计算恰好到达楼顶的不同方法数。每次步长组成的序列不同，就视为不同方法。

## ACM 输入格式

输入一行一个整数 n。

## 输出格式

输出一行一个整数，表示不同方法数。

## 样例

输入：

```text
3
```

输出：

```text
3
```

说明：三种方法为：1 + 1 + 1、1 + 2、2 + 1。

## 主要数据范围

1 ≤ n ≤ 45。
