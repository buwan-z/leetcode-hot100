# 322. 零钱兑换（Coin Change）

来源：[LeetCode 322](https://leetcode.cn/problems/coin-change/)，属于 LeetCode Hot 100。本题将原题改编为 ACM 标准输入输出格式；每次运行只处理一组数据。

## 中文题意

给定 n 种硬币的面额 coins 和目标金额 amount，每种硬币都有无限枚。求恰好凑出目标金额所需要的最少硬币数。若无法凑出，输出 -1；目标金额为 0 时需要 0 枚硬币。

## ACM 输入格式

第一行两个整数 n、amount。
第二行 n 个正整数，表示硬币面额。

## 输出格式

输出一行一个整数，表示最少硬币数，无法凑出时输出 -1。

## 样例

输入：

```text
3 11
1 2 5
```

输出：

```text
3
```

说明：11 = 5 + 5 + 1，最少需要 3 枚硬币。

## 主要数据范围

1 ≤ n ≤ 12；1 ≤ coins[i] ≤ 2^31 - 1；0 ≤ amount ≤ 10^4。
