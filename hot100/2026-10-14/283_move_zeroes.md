# 283. 移动零（Move Zeroes）

来源：[LeetCode 283](https://leetcode.cn/problems/move-zeroes/)，属于 LeetCode Hot 100。本题将原题改编为 ACM 标准输入输出格式；每次运行只处理一组数据。

## 中文题意

给定整数数组 nums，将所有 0 移动到数组末尾，并保持所有非零元素原来的相对顺序。要求在原数组上原地操作，不复制整个数组，使用 O(1) 额外空间。

## ACM 输入格式

第一行一个整数 n，表示数组长度。
第二行 n 个整数，表示 nums。

## 输出格式

输出一行 n 个整数，表示移动零后的数组，用空格分隔。

## 样例

输入：

```text
5
0 1 0 3 12
```

输出：

```text
1 3 12 0 0
```

说明：非零元素 1、3、12 的相对顺序不变，两个零移动到末尾。

## 主要数据范围

1 ≤ n ≤ 10^4；-2^31 ≤ nums[i] ≤ 2^31 - 1。
