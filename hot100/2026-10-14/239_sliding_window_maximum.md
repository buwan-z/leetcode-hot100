# 239. 滑动窗口最大值（Sliding Window Maximum）

来源：[LeetCode 239](https://leetcode.cn/problems/sliding-window-maximum/)，属于 LeetCode Hot 100。本题将原题改编为 ACM 标准输入输出格式；每次运行只处理一组数据。

## 中文题意

给定长度为 n 的整数数组 nums 和窗口大小 k。窗口最初覆盖前 k 个元素，然后每次向右移动一个位置，直到覆盖数组最后 k 个元素。按窗口出现的顺序输出每个窗口内的最大值。

## ACM 输入格式

第一行两个整数 n、k。
第二行 n 个整数，表示 nums。

## 输出格式

输出一行 n - k + 1 个整数，表示从左到右各窗口的最大值，用空格分隔。

## 样例

输入：

```text
8 3
1 3 -1 -3 5 3 6 7
```

输出：

```text
3 3 5 5 6 7
```

说明：共有 6 个窗口，最大值依次为 3、3、5、5、6、7。

## 主要数据范围

1 ≤ n ≤ 10^5；1 ≤ k ≤ n；-10^4 ≤ nums[i] ≤ 10^4。
