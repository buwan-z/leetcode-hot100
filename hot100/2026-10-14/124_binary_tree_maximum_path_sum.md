# 124. 二叉树中的最大路径和（Binary Tree Maximum Path Sum）

来源：[LeetCode 124](https://leetcode.cn/problems/binary-tree-maximum-path-sum/)，属于 LeetCode Hot 100。本题将原题改编为 ACM 标准输入输出格式；每次运行只处理一组数据。

# 中文题意

给定一棵非空二叉树。一条路径是由至少一个节点构成的序列，相邻节点之间有树上的边，同一节点至多出现一次。路径可以从任意节点开始、在任意节点结束，不一定经过根，也不要求始终向下。求所有路径中节点值之和的最大值。

## ACM 输入格式

第一行一个整数 L，表示层序序列的 token 数（包含 null）。第二行 L 个用空格分隔的 token，整数表示节点值，null 表示空节点。

层序序列采用 LeetCode 的队列格式：从根开始，依次为队列中每个非空节点读取左、右孩子；null 不入队，也不再占用孩子位置。末尾空节点可省略，序列结束后未给出的孩子均为空。输入保证可构成合法二叉树。请据此构建节点及左右孩子关系。

本题树非空，根节点一定是整数。

## 输出格式

输出一行一个整数，表示最大路径和。

## 样例

输入：

```text
7
-10 9 20 null null 15 7
```

输出：

```text
42
```

说明：最优路径为 15 → 20 → 7，节点值之和为 42。

## 主要数据范围

实际节点数为 1～3 × 10^4；-1000 ≤ 节点值 ≤ 1000；1 ≤ L ≤ 60001。
