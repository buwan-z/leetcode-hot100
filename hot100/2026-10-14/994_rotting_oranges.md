# 994. 腐烂的橘子（Rotting Oranges）

来源：[LeetCode 994](https://leetcode.cn/problems/rotting-oranges/)，属于 LeetCode Hot 100。本题将原题改编为 ACM 标准输入输出格式；每次运行只处理一组数据。

## 中文题意

给定 m 行 n 列网格，0 表示空格子，1 表示新鲜橘子，2 表示腐烂橘子。每过一分钟，所有腐烂橘子同时使上下左右相邻的新鲜橘子腐烂；本分钟刚腐烂的橘子到下一分钟才继续传播。求网格中不再有新鲜橘子的最小分钟数。若无法使全部新鲜橘子腐烂，输出 -1；若最初没有新鲜橘子，输出 0。

## ACM 输入格式

第一行两个整数 m、n。
接下来 m 行，每行 n 个整数，表示网格，用空格分隔。

## 输出格式

输出一行一个整数，表示所需最小分钟数或 -1。

## 样例

输入：

```text
3 3
2 1 1
1 1 0
0 1 1
```

输出：

```text
4
```

说明：腐烂同时向四个方向传播，4 分钟后全部新鲜橘子均已腐烂。

## 主要数据范围

1 ≤ m, n ≤ 10；grid[i][j] ∈ {0, 1, 2}。
