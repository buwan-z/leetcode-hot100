# 438. 找到字符串中所有字母异位词（Find All Anagrams in a String）

来源：[LeetCode 438](https://leetcode.cn/problems/find-all-anagrams-in-a-string/)，属于 LeetCode Hot 100。本题将原题改编为 ACM 标准输入输出格式；每次运行只处理一组数据。

## 中文题意

给定两个字符串 s 和 p，找出 s 中所有与 p 互为字母异位词的连续子串，输出其起始下标。字母异位词是各字符及其出现次数完全相同、排列顺序可以不同的字符串。下标从 0 开始。

## ACM 输入格式

第一行字符串 s。
第二行字符串 p。

## 输出格式

第一行输出符合条件的起始下标数量 k。若 k > 0，第二行按升序输出 k 个下标，用空格分隔；若 k = 0，只输出第一行。

## 样例

输入：

```text
cbaebabacd
abc
```

输出：

```text
2
0 6
```

说明：起始下标 0 的子串 cba 和起始下标 6 的子串 bac 均与 abc 互为字母异位词。

## 主要数据范围

1 ≤ |s|, |p| ≤ 3 × 10^4；两个字符串仅包含小写英文字母。
