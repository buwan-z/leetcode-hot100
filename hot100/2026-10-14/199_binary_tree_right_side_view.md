# 199. 二叉树的右视图（Binary Tree Right Side View）

来源：[LeetCode 199](https://leetcode.cn/problems/binary-tree-right-side-view/)，属于 LeetCode Hot 100。本题将原题改编为 ACM 标准输入输出格式；每次运行只处理一组数据。

## 中文题意

给定一棵二叉树，从树的右侧观察，输出从上到下每一层能看到的节点值，即该层最右侧的节点值。空树没有可见节点。

## ACM 输入格式

第一行一个整数 L，表示层序序列的 token 数（包含 null）。第二行 L 个用空格分隔的 token，整数表示节点值，null 表示空节点。

层序序列采用 LeetCode 的队列格式：从根开始，依次为队列中每个非空节点读取左、右孩子；null 不入队，也不再占用孩子位置。末尾空节点可省略，序列结束后未给出的孩子均为空。输入保证可构成合法二叉树。请据此构建节点及左右孩子关系。

空树用 L = 0 表示，此时没有第二行。

## 输出格式

第一行输出可见节点数 k。若 k > 0，第二行按从上到下的顺序输出 k 个节点值，用空格分隔；若 k = 0，只输出第一行。

## 样例

输入：

```text
7
1 2 3 null 5 null 4
```

输出：

```text
3
1 3 4
```

说明：从上到下，最右侧节点分别为 1、3、4。

## 主要数据范围

实际节点数为 0～100；-100 ≤ 节点值 ≤ 100；L = 0 或 1 ≤ L ≤ 201。
