# LeetCode 138. 随机链表的复制

原题：[Copy List with Random Pointer](https://leetcode.cn/problems/copy-list-with-random-pointer/)

以下为单组测试数据的 ACM 输入输出改编。

## 中文题意

给定一个带 random 指针的单链表，构造它的深拷贝。每个新节点的值应与对应原节点相同，next 与 random 应指向对应的新节点或空指针；任何新节点指针都不得指向原节点。必须创建全新的节点，保留原链表。完成后按下述格式输出新链表。

## ACM 输入格式

第一行一个整数 n。随后 n 行依次描述编号 0 至 n-1 的节点，每行两个整数 value 和 random_index。next 按编号顺序指向下一个节点，最后一个节点的 next 为空；random_index=-1 表示空指针，否则指向该编号节点。n=0 时没有节点行，头指针为空。

## 输出格式

第一行输出复制链表的节点数 n。随后按新链表 next 顺序输出 n 行，每行 value random_index；新节点依次重新编号为 0 至 n-1，random_index 使用新链表编号，空指针输出 -1。因此正确输出的序列化内容与输入相同。

## 样例

输入：

```text
3
7 -1
13 0
11 2
```

输出：

```text
3
7 -1
13 0
11 2
```

说明：复制后的三个节点保持原值；第二个新节点的 random 指向第一个新节点，第三个指向自身。ACM 输出只验证结构，无法验证对象独立性；练习时应实际构造链表并深拷贝，而非直接回显输入，可自行修改复制节点确认原节点未变化。

## 主要数据范围

0 ≤ n ≤ 1000；-10000 ≤ value ≤ 10000；random_index 为 -1 或 [0, n-1] 内的整数。
