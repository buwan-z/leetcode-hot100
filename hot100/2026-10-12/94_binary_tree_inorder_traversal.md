# LeetCode 94. 二叉树的中序遍历

原题：[Binary Tree Inorder Traversal](https://leetcode.cn/problems/binary-tree-inorder-traversal/)

以下为单组测试数据的 ACM 输入输出改编。

## 中文题意

给定一棵二叉树，输出其中序遍历的节点值序列。中序遍历顺序为：先左子树，再当前节点，最后右子树。可使用递归，也可尝试迭代。

## ACM 输入格式

第一行两个整数 n 和 root。随后 n 行依次描述编号 1 至 n 的节点，每行三个整数 value left right。left、right 为左右孩子编号，0 表示没有该孩子。n=0 时 root=0；否则 root 为合法编号。保证输入是一棵合法二叉树，所有节点均属于该树。

## 输出格式

输出一行中序遍历的节点值，相邻值用一个空格分隔。空树输出一个空行。

## 样例

输入：

```text
3 1
1 0 2
2 3 0
3 0 0
```

输出：

```text
1 3 2
```

说明：根节点值为 1，右孩子值为 2，右孩子的左孩子值为 3，因此中序为 1、3、2。

## 主要数据范围

0 ≤ n ≤ 100；-100 ≤ value ≤ 100；孩子编号为 0 或 [1, n] 内的整数。
