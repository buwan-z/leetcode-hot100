# 15. 三数之和（LeetCode 15）

给定整数数组 `nums`，找出所有满足 `nums[i] + nums[j] + nums[k] == 0` 的三元组，要求 `i`、`j`、`k` 互不相同。答案中不能包含重复的三元组。

## ACM 输入格式

第一行输入整数 `n`；第二行输入 `n` 个整数，表示 `nums`。

## 输出格式

第一行输出不同三元组的数量 `k`。接下来 `k` 行，每行输出一个三元组的三个数，按非降序排列。各行顺序不限。

## 样例

输入：
```text
6
-1 0 1 2 -1 -4
```

输出（行顺序不限）：
```text
2
-1 -1 2
-1 0 1
```

## 数据范围

- `3 <= n <= 3000`
- `-10^5 <= nums[i] <= 10^5`
