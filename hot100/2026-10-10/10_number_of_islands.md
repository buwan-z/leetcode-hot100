# 200. 岛屿数量（LeetCode 200）

给定由字符 `'1'`（陆地）和 `'0'`（水）组成的二维网格。岛屿由水平或垂直方向相邻的陆地连接形成，网格边缘之外均视为水。求岛屿数量。

## ACM 输入格式

第一行输入两个整数 `m n`，分别表示行数和列数。接下来 `m` 行，每行输入一个长度为 `n`、只含 `0` 和 `1` 的字符串。

## 输出格式

输出岛屿数量。

## 样例

输入：
```text
4 5
11110
11010
11000
00000
```

输出：
```text
1
```

## 数据范围

- `1 <= m, n <= 300`
- 网格只包含字符 `0` 和 `1`。
