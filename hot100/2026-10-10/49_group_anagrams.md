# 49. 字母异位词分组（LeetCode 49）

给定字符串数组 `strs`，将由相同字母组成的字符串分到同一组。输入字符串只包含小写英文字母。

## ACM 输入格式

第一行输入整数 `n`；接下来 `n` 行，每行输入一个字符串。

## 输出格式

第一行输出分组数量 `k`。接下来 `k` 行，每行先输出组内字符串数量 `m`，再输出该组的 `m` 个字符串，以空格分隔。为了统一输出，每组内字符串按字典序排列，各组按每组的首个字符串字典序排列。

## 样例

输入：
```text
6
eat
tea
tan
ate
nat
bat
```

输出：
```text
3
1 bat
3 ate eat tea
2 nat tan
```

## 数据范围

- `1 <= n <= 10^4`
- `1 <= len(strs[i]) <= 100`
- `strs[i]` 只包含小写英文字母。
