# 08. 二叉树的中序遍历（LeetCode 94）

## 中文题意

给定一棵二叉树，按“左子树、当前节点、右子树”的顺序遍历，输出节点值序列。空树的遍历结果为空。可进一步尝试用迭代方式完成遍历。

## ACM 输入格式

单组数据。第一行输入节点数 `n`。若 `n > 0`，接下来 `n` 行，第 `i` 行输入 `value left right`，表示编号为 `i` 的节点值、左孩子编号、右孩子编号。节点编号为 `1..n`，根节点为 1，孩子编号 0 表示不存在。保证输入构成合法二叉树，所有节点均可从根到达。`n = 0` 时没有后续节点行。这是本练习使用的节点表格式。

## 输出格式

一行输出中序遍历得到的 `n` 个节点值，以空格分隔。空树只输出一个换行符。

## 样例

输入：

```text
3
1 0 2
2 3 0
3 0 0
```

输出：

```text
1 3 2
```

## 主要数据范围

- `0 <= n <= 100`。
- `-100 <= value <= 100`。
- `0 <= left, right <= n`。
