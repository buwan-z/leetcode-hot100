# 05. 二叉树的直径（LeetCode 543）

## 中文题意

给定一棵二叉树，求任意两个节点之间最长简单路径的长度。路径可以不经过根节点，长度按边数计算，单节点树的直径为 0。

## ACM 输入格式

单组数据。第一行输入节点数 `n`。接下来 `n` 行，第 `i` 行输入三个整数 `value left right`，表示编号为 `i` 的节点值、左孩子编号、右孩子编号。节点编号为 `1..n`，根节点固定为 1，孩子编号为 0 表示不存在。保证输入构成合法二叉树，所有节点均可从根到达。这是本练习使用的节点表格式。

## 输出格式

输出一个整数，表示二叉树的直径。

## 样例

输入：

```text
5
1 2 3
2 4 5
3 0 0
4 0 0
5 0 0
```

输出：

```text
3
```

说明：节点编号路径 `4 -> 2 -> 1 -> 3` 包含 3 条边。

## 主要数据范围

- `1 <= n <= 10^4`。
- `-100 <= value <= 100`。
- `0 <= left, right <= n`，树的高度最多为 `n`。
