# 01. 最小覆盖子串（LeetCode 76）

## 中文题意

给定字符串 `s` 和 `t`，求 `s` 中包含 `t` 所有字符的最短连续子串。重复字符也必须按次数包含，大小写视为不同字符。若无符合要求的子串，输出空行；保证有解时最短答案唯一。尝试达到 O(|s| + |t|) 时间复杂度。

## ACM 输入格式

单组数据。第一行是 `s`，第二行是 `t`，不含引号或空格。

## 输出格式

输出最短覆盖子串。无解时只输出一个换行符。

## 样例

输入：

```text
ADOBECODEBANC
ABC
```

输出：

```text
BANC
```

## 主要数据范围

- `1 <= |s|, |t| <= 10^5`。
- 两个字符串仅包含大小写英文字母。
