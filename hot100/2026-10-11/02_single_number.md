# 02. 只出现一次的数字（LeetCode 136）

## 中文题意

给定非空整数数组，恰有一个整数只出现一次，其余每个不同整数都出现两次。找出只出现一次的整数。要求时间复杂度 O(n)，额外空间复杂度 O(1)。

## ACM 输入格式

单组数据。第一行输入整数 `n`，第二行输入 `n` 个空格分隔的整数。

## 输出格式

输出只出现一次的整数。

## 样例

输入：

```text
5
4 1 2 1 2
```

输出：

```text
4
```

## 主要数据范围

- `1 <= n <= 30000`。
- `-30000 <= nums[i] <= 30000`。
- 保证出现次数满足题意。
