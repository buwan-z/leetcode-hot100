# 04. 移动零（LeetCode 283）

## 中文题意

给定整数数组，将全部零移动到数组末尾，同时保持非零元素原有的相对顺序。要求在读入的数组上原地修改，不复制整个数组，使用 O(1) 额外空间。

## ACM 输入格式

单组数据。第一行输入整数 `n`，第二行输入 `n` 个空格分隔的整数。

## 输出格式

输出修改后的 `n` 个整数，以空格分隔。

## 样例

输入：

```text
5
0 1 0 3 12
```

输出：

```text
1 3 12 0 0
```

## 主要数据范围

- `1 <= n <= 10^4`。
- `-2^31 <= nums[i] <= 2^31 - 1`。
