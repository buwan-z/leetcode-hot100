# 03. 找到字符串中所有字母异位词（LeetCode 438）

## 中文题意

给定字符串 `s` 和 `p`，找出 `s` 中所有与 `p` 互为字母异位词的连续子串，输出它们的起始下标。字母异位词具有相同的字符及各字符出现次数，字符顺序可以不同。下标从 0 开始。

## ACM 输入格式

单组数据。第一行输入 `s`，第二行输入 `p`，不含引号或空格。

## 输出格式

第一行输出匹配数量 `k`。第二行按升序输出 `k` 个起始下标，以空格分隔。`k = 0` 时第二行为空行。

## 样例

输入：

```text
cbaebabacd
abc
```

输出：

```text
2
0 6
```

## 主要数据范围

- `1 <= |s|, |p| <= 30000`。
- 两个字符串仅包含小写英文字母。
- 若 `|p| > |s|`，匹配数量为 0。
