# 09. 最小路径和（LeetCode 64）

## 中文题意

给定一个由非负整数构成的 `m` 行 `n` 列网格，从左上角走到右下角，每一步只能向右或向下移动一格。求路径上所有格子数值之和的最小值，起点和终点都计入总和。

## ACM 输入格式

单组数据。第一行输入 `m n`。接下来 `m` 行，每行输入 `n` 个空格分隔的整数。

## 输出格式

输出一个整数，表示最小路径和。

## 样例

输入：

```text
3 3
1 3 1
1 5 1
4 2 1
```

输出：

```text
7
```

说明：一条最优路径上的数值依次为 `1 3 1 1 1`。

## 主要数据范围

- `1 <= m, n <= 200`。
- `0 <= grid[i][j] <= 200`。
