# LeetCode 19 · 删除链表的倒数第 N 个结点

题目来源：[LeetCode 19](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/) · [Hot 100](https://leetcode.cn/studyplan/top-100-liked/)。本练习将函数接口改编为标准输入输出。

## 中文题意
给定一个无环单向链表，删除其倒数第 k 个结点。倒数第 1 个结点是尾结点。输出删除后从头到尾的结点值。
练习时请将输入值构建为单向链表，通过修改 next 指针完成删除。可尝试只扫描链表一趟。
## ACM 输入格式
第一行两个整数 n 和 k，分别表示结点数和需要删除的倒数位置。
第二行 n 个以空格分隔的整数，按从头到尾的顺序给出结点值。相邻输入结点通过 next 指针相连，最后一个结点的 next 为空。
输入仅包含一组数据。
## 输出格式
第一行输出删除后的结点数，即 n - 1。
第二行按从头到尾输出剩余结点值，以一个空格分隔；若链表为空，第二行输出空行。
## 样例
输入：
```text
5 2
1 2 3 4 5
```
输出：
```text
4
1 2 3 5
```
解释：倒数第 2 个结点的值为 4。
## 主要数据范围
- 1 ≤ n ≤ 30。
- 1 ≤ k ≤ n。
- 0 ≤ 结点值 ≤ 100。
