# LeetCode 73 · 矩阵置零

题目来源：[LeetCode 73](https://leetcode.cn/problems/set-matrix-zeroes/) · [Hot 100](https://leetcode.cn/studyplan/top-100-liked/)。本练习将函数接口改编为标准输入输出。

## 中文题意
给定整数矩阵，将原矩阵中每个零元素所在的整行和整列全部置为零。判定哪些行列需要置零时，以修改前的矩阵为准；新产生的零不会继续触发其他行列置零。
请原地修改存储输入矩阵的二维数组。进阶要求：除该矩阵和输入输出所需空间外，只使用 O(1) 额外空间。
## ACM 输入格式
第一行两个整数 m 和 n，表示矩阵行数和列数。
接下来 m 行，每行 n 个以空格分隔的整数。
输入仅包含一组数据。
## 输出格式
输出修改后的矩阵，共 m 行，每行 n 个整数，整数间以一个空格分隔。
## 样例
输入：
```text
3 3
1 1 1
1 0 1
1 1 1
```
输出：
```text
1 0 1
0 0 0
1 0 1
```
## 主要数据范围
- 1 ≤ m, n ≤ 200。
- -2^31 ≤ matrix[i][j] ≤ 2^31 - 1。
