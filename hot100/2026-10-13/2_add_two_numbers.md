# LeetCode 2 · 两数相加

题目来源：[LeetCode 2](https://leetcode.cn/problems/add-two-numbers/) · [Hot 100](https://leetcode.cn/studyplan/top-100-liked/)。本练习将函数接口改编为标准输入输出。

## 中文题意

给定两个非空单向链表，分别表示两个非负整数。每个结点存储一位十进制数字，链表从头到尾按低位到高位的逆序存储，例如 [2, 4, 3] 表示 342。
将两个整数相加，并以同样的逆序链表形式输出结果。除整数 0 本身外，输入整数没有前导零。
练习时请构建两个单向链表，并逐结点计算和、构建结果链表。

## ACM 输入格式

第一行两个整数 n 和 m，表示两个链表的结点数。
第二行 n 个整数，给出第一个链表从头到尾的结点值。
第三行 m 个整数，给出第二个链表从头到尾的结点值。
每个链表相邻结点通过 next 指针相连，尾结点的 next 为空。
输入仅包含一组数据。

## 输出格式

第一行输出结果链表的结点数 L。
第二行输出 L 个以空格分隔的数字，按结果链表从头到尾的顺序排列，即从低位到高位。
结果不得有多余的高位零；和为 0 时输出一个值为 0 的结点。

## 样例

输入：

```text
3 3
2 4 3
5 6 4
```

输出：

```text
3
7 0 8
```

解释：342 + 465 = 807。

## 主要数据范围

- 1 ≤ n, m ≤ 100。
- 每个结点值在 0 到 9 之间。
- 当链表长度大于 1 时，尾结点值非零。
